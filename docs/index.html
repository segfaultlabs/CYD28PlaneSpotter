CYD Plane Spotter — Web Flashing

Flash prebuilt firmware directly from your browser — no PlatformIO or Arduino IDE install needed. Works in Chrome or Edge (desktop) over a USB cable, using the WebSerial API.

WiFi credentials and home location aren't configurable from this page yet — the firmware ships with whatever was baked into src/config.env at build time. See the README for building your own with your own WiFi credentials via PlatformIO instead.
